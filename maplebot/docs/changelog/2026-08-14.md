# 2026-08-14 变更日志

## 新增 `tools/detect_mobs.py` — YOLO 怪物侦测即时预览

### 问题
需要一个独立脚本，启动后按窗口标题抓画面、用训练好的 YOLO 模型检测怪物并显示匹配度，
用于快速验证模型在真实游戏画面的效果，不跑完整 bot 管道。

### 修改
新增 `tools/detect_mobs.py`，复用既有组件：
- `maplebot.capture.WindowCapture` 抓指定标题窗口（PrintWindow 优先，被盖也准）
- `maplebot.vision.yolo_mobs.YoloMobDetector` 推理（ONNX/PT 都收）
- 画面叠黄框 + 红十字中心 + 置信度文字，终端每 0.5s 打印「检测到 N 个怪物」+ 每怪坐标/匹配度
- 支持 `--snapshot out.png` 离线存图，`--confidence` 调门檻，`--title` 指定窗口

### 影响范围
仅新增一个独立调试脚本，不触碰主循环、配置、检测器实现，零副作用。
